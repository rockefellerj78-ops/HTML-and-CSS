Подсказка — CSS
.flex-container {
  display: flex;
}
.flex-item {
  text-align: center;
  padding: 1.5em;
  color: white;
}
.c1 { background-color: #675BA7; }
.c2 { background-color: #9BC850; }
.c3 { background-color: #A62E5C; }
Подсказка — HTML
<div class="flex-container">
  <div class="flex-item c1">Flex Item 1</div>
  <div class="flex-item c2">Flex Item 2</div>
  <div class="flex-item c3">Flex Item 3</div>
</div>
Два главных понятия: flex-container — родитель с display: flex, flex-item — его прямые дети. Значения flex-direction: row (строка, по умолчанию), row-reverse (строка справа налево), column (столбик), column-reverse (столбик снизу вверх). Есть ещё display: inline-flex — тот же flex, но сам контейнер ведёт себя как строчный элемент.

Подсказка — CSS
.flex-container {
  display: flex;
  flex-wrap: wrap;
  width: 60%;
}
/* короткая запись направления + переноса */
.flex-container {
  flex-flow: row wrap;
}
/* изменение порядка */
.group1 { order: -1; }  /* в начало */
.group2 { order: 1; }   /* в конец */
Про значения: flex-wrap бывает nowrap (без переноса, по умолчанию), wrap (перенос), wrap-reverse (перенос в обратном порядке). flex-flow — короткая запись сразу для direction и wrap: flex-flow: row wrap. У свойства order по умолчанию значение 0 — чем меньше число, тем раньше элемент.

Превью — align-self у отдельных блоков
stretch
align-self: flex-start

Подсказка — CSS
/* выравнивание по главной оси */
.container1 {
  display: flex;
  justify-content: space-between;
}
/* выравнивание по поперечной оси */
.container2 {
  display: flex;
  height: 7em;
  align-items: center;
}
/* своё выравнивание для одного блока */
.item2 { align-self: flex-start; }
.item3 { align-self: flex-end; }
Две оси: justify-content работает вдоль главной оси (куда смотрит flex-direction), а align-items — вдоль поперечной (перпендикулярной). Значения justify-content: flex-start, flex-end, center, space-between, space-around. Значения align-items: stretch (по умолчанию, тянет на всю высоту), flex-start, flex-end, center, baseline. align-self переопределяет align-items для конкретного блока.

Гибкие размеры — flex-grow, shrink, basis
распределение свободного места, шорткат flex
Заблокировано ▶
Задание
Создайте контейнер с тремя блоками. Первому задайте flex-grow: 0 (не растягивается), второму flex-grow: 1, третьему flex-grow: 2. Посмотрите, как свободное место распределяется: третий блок получит вдвое больше второго. Затем перепишите всё через короткий шорткат flex.
Превью — flex-grow: 0 / 1 / 2
grow: 0
grow: 1
grow: 2
Первый блок фиксирован, остальные делят свободное место в пропорции 1:2
Подсказка — три отдельных свойства
.item1 { flex-grow: 0; flex-basis: 80px; }
.item2 { flex-grow: 1; }
.item3 { flex-grow: 2; }
Подсказка — шорткат flex
/* flex: [grow] [shrink] [basis] */
.item1 { flex: 0 0 auto; }   /* = flex: none */
.item2 { flex: 1 1 auto; }   /* = flex: auto */
.item3 { flex: 0 1 auto; }   /* = flex: initial */
Что значит каждое свойство:
• flex-basis — начальный размер блока до распределения места
• flex-grow — насколько блок растягивается, когда есть лишнее место (доли)
• flex-shrink — насколько блок сжимается, когда места не хватает
Шорткат: flex: none (= 0 0 auto, не тянется и не жмётся), flex: auto (= 1 1 auto), flex: initial (= 0 1 auto).

Самостоятельное задание — адаптивный макет
flexbox + media query: столбик на мобиле, строка на десктопе
Заблокировано ▶
Задание
Соберите адаптивный макет сайта на flexbox. Требования:

1. Структура: header, main (внутри — article, nav, aside), footer
2. На узком экране всё идёт столбиком (flex-direction: column), причём nav поднят над article через order: -1
3. На широком экране (от 600px) через медиазапрос main переключается в строку (flex-direction: row): article в центре широкий (flex: 2 2 12em), nav и aside по бокам узкие (flex: 1)
4. header и footer фиксированной высоты (flex: 0 0 5em)

Подсказка по медиазапросу: базовые стили пишутся для мобильного (столбик), а внутри @media screen and (min-width: 600px) { ... } переопределяется main { flex-direction: row; }. Это подход «mobile first» — сначала простой мобильный макет, потом усложнение для широких экранов.
