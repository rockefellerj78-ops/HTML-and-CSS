Функция repeat() и единицы fr
repeat(n, размер), доли свободного пространства
Заблокировано ▶
Задание
Перепишите сетку из шага 1 так, чтобы строки задавались через функцию repeat(2, 4em), а столбцы — через гибкие единицы 1fr 2fr 1fr. Единица fr делит доступную ширину между столбцами пропорционально: средний столбец будет в 2 раза шире крайних. Добавьте промежутки между ячейками через свойство gap.

Grid Item 1
Grid Item 2

Средний столбец вдвое шире крайних, между ячейками отступ 6px
Подсказка — CSS
.grid-container {
  border: solid 2px #000;
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-rows: repeat(2, 4em);
  gap: 6px;
}
Формула для fr: доля столбца = его_fr × доступное_пространство / сумма_всех_fr. При 1fr 2fr 1fr сумма = 4, средний столбец получает 2/4 ширины, крайние — по 1/4. Свойство repeat(2, 4em) — короткая запись для 4em 4em. Можно повторять и более сложные шаблоны: repeat(2, 7em 8em) даст четыре столбца 7em, 8em, 7em, 8em.
Про gap: единое свойство gap задаёт промежутки сразу по обеим осям. Можно указать два значения — gap: 10px 20px (между строками 10px, между столбцами 20px). Раньше эти свойства назывались grid-gap, grid-row-gap, grid-column-gap — все три варианта работают.

Размещение элементов на линиях
grid-column, grid-row, span
Заблокировано ▶
Задание
Создайте сетку 4×3 (четыре столбца, три строки) с шестью блоками. Сделайте первый блок большим — он должен занимать первые две строки и два первых столбца. Третий блок растяните на два столбца в первой строке. Используйте свойства grid-column и grid-row с ключевым словом span.
Превью результата
Grid Item 1
Grid Item 2
Grid Item 3
Grid Item 4
Grid Item 5
Grid Item 6
Первый блок занимает 2×2 ячейки, третий — две ячейки в строку
Подсказка — CSS
.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: repeat(3, 4em);
  gap: 6px;
  border: solid 2px #000;
}
.big {
  grid-column: 1 / span 2;
  grid-row: 1 / span 2;
}
.wide {
  grid-column: 3 / 5;
}
Линии и span: grid-линии — это разделители между ячейками. У сетки из 4 столбцов линий 5: от 1 до 5. grid-column: 1 / 3 значит «занять от линии 1 до линии 3», то есть 2 ячейки. То же самое можно записать как grid-column: 1 / span 2 — «начать с линии 1 и растянуться на 2 ячейки». Оба варианта дают одинаковый результат.
Полные и короткие формы:
• grid-column-start: 1; grid-column-end: 3; — длинная форма
• grid-column: 1 / 3 — короткая через слэш
• grid-column: 1 / span 2 — через span
• grid-area: 1 / 1 / 3 / 3 — всё сразу: row-start / col-start / row-end / col-end

Именованные области — grid-template-areas
grid-template-areas, grid-area для разметки страницы
Заблокировано ▶
Задание
Сделайте макет страницы с тремя зонами: шапка наверху во всю ширину, слева сайдбар, справа основное содержимое, снизу подвал во всю ширину. Используйте grid-template-areas для именования зон и grid-area для привязки элементов.
Превью результата
Header
Sidebar
Content
Footer
Подсказка — CSS
.grid-container {
  display: grid;
  grid-template-areas:
    "header  header  header"
    "sidebar content content"
    "footer  footer  footer";
  grid-template-columns: 120px 1fr 1fr;
  grid-template-rows: 50px 130px 40px;
  gap: 6px;
  border: solid 2px #000;
}
.header  { grid-area: header;  background: #263238; }
.sidebar { grid-area: sidebar; background: #455a64; }
.content { grid-area: content; background: #37474f; }
.footer  { grid-area: footer;  background: #263238; }
Подсказка — HTML
<div class="grid-container">
  <div class="header">Header</div>
  <div class="sidebar">Sidebar</div>
  <div class="content">Content</div>
  <div class="footer">Footer</div>
</div>
Как читать grid-template-areas: каждая строка в кавычках — это одна строка сетки. Слова — имена зон. Повторение имени растягивает зону на соседние ячейки. Чтобы оставить ячейку пустой — пишут точку . вместо имени.
